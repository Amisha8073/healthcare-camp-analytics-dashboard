# Healthcare Camp Analytics Dashboard

## Project Overview
This project focuses on analyzing healthcare camp data using interactive dashboards and visualization techniques.

The dashboard provides insights into:
- Patient participation
- Donation trends
- Health scores
- Camp performance

---

## Tools Used
- Excel
- SQL
- Looker Studio

---

## Key Insights
- Analyzed donation distribution across health camps
- Compared patient participation trends
- Monitored average health scores
- Built KPI-based reporting dashboard
